# 📸 Insta Manager Bot — Instagram Automation & Analytics Tool

Insta Manager Bot is a Flask-based web application designed to automate Instagram account insights and user interaction tracking.  
This tool helps users view engagement patterns, track analytics, and simplify frequent tasks — all from an easy web interface.

---

## 🚀 Features

- 🔐 Secure Login with session support
- 📊 View & analyze profile activity in a clean dashboard
- 🧲 Auto-collection of follower and engagement data
- 🗂️ Local SQLite database storage
- 🌐 Web-based UI built using Flask templates

---

## 🛠 Tech Stack

| Component | Technology |
|----------|------------|
| Backend | Python (Flask) |
| Database | SQLite |
| Frontend | HTML, CSS, Jinja Templates |
| Tools | Requests, Automation Scripts |
